# 一页项目概览

## 工程问题

模型解释不是业务授权；审批后状态漂移、重复请求、跨用户访问或提示补丁都不能绕过提交安全检查。

## 设计取舍

Python + Pydantic 表达请求与权威快照；领域接口隔离通用治理与业务；审批绑定参数和状态，提交复核配合 CAS。Skill 负责只读解释；自进化限制补丁、经验来源与评测分区，晋升和回滚分别审批。

## 可复现展示

330 项公开合成回归、四个示例、两套冻结 Registry 校验。源码与安装资源副本逐字节同步，并验证 wheel/sdist 安装后运行。见 [README](README.md)。

## 历史实验，不作新成绩

Benchmark112：56 家族、14 机制、112 对真实模型审查。模型建议的经济解释覆盖率 50.89% → 94.64%，SOC 解释覆盖率 55.36% → 95.54%。回答变长，P95 13.58 → 18.56 秒，换序一致性 17/28，争议未人工确认。无正式晋升，不能表述为生产收益或人类认可率。

## 边界

当前 4.0.0.dev5 不是 RC1。演示不调用真实模型、数据库或设备；不提供企业源码与私有证据。冻结安全核心、运行 Prompt、Registry 和原 Gold 不变。权属未确认，暂不能公开发布。
